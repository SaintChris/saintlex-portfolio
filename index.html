engineering_workflow.md ENGINEERING METHOD
  1. 01
    Define

    Confirm the objective, system boundary, constraints, data sources, and expected behavior.

  2. 02
    Observe

    Collect evidence from devices, networks, APIs, logs, workflows, and system state before changing anything.

  3. 03
    Test

    Use controlled, reversible checks and compare expected versus actual behavior.

  4. 04
    Implement

    Apply the smallest maintainable change with security, rollback, and operational impact in mind.

  5. 05
    Verify

    Validate the result, document evidence, and record follow-up or monitoring requirements.
