# Contributing to Alex Bogle Portfolio

Thank you for your interest in improving this portfolio site.

## How to Contribute
1. **Fork the repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/yourusername/saintlex-portfolio.git
   cd saintlex-portfolio
   ```
3. **Create a branch** for your changes:
   ```bash
   git checkout -b my-feature
   ```
4. **Make your changes** (HTML, CSS, content, etc.).
5. **Run a local server** to preview:
   ```bash
   python3 -m http.server 8000
   open http://localhost:8000
   ```
6. **Commit with a clear message**:
   ```bash
   git commit -m "feat: update project card styling"
   ```
7. **Push and open a Pull Request** against the `main` branch.

## Code Style
- Keep HTML tidy; use meaningful indentation.
- For any CSS, follow the Tailwind utility‑first approach.
- Keep lines under 120 characters.

## Review Process
- Maintainers will review PRs for style and correctness.
- Automated CI checks (Markdown lint) run on each PR.

## Issues
- Use the GitHub Issues tab.
- Provide a clear title, description, and any necessary screenshots.

## Thanks
Your contributions help showcase my work and improve the site for everyone.
