// 5-Layer Memory Architecture
①
Honcho (Vector + Cache)
Cross-session user modeling, peer cards, dialectic reasoning. pgvector + Redis. FastAPI at localhost:8000.
hybrid recall · qwen3:1.7b
②
soul.md + agents.md
Personality, rules, preferences, communication style. Injected into every single prompt automatically.
every prompt · identity
③
Obsidian Vault
102 pages, 15 MB. Project statuses, daily logs, mistake records, session summaries, handoffs.
102 pages · knowledge
④
Built-in Memory
2,200 char hard limit. Only routing essentials: Telegram IDs, email prefs, critical paths.
minimal · essential
⑤
Session Search
SQLite FTS5 full-text search across 359 MB of raw conversational history. On-demand recall.
359 MB · FTS5
🔗
Inbox Bridge
inbox_bridge.py runs every 5 min. Routes handoff files between 6 agent inboxes. Async file-based.
5 min · async · 6 inboxes
